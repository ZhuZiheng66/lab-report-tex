# lab-profile.md 模板

把下面内容存成课程文件夹根目录的 `lab-profile.md`，填好后每次做报告自动读取。**这个文件含个人信息，不要提交到公开仓库**（仓库的 .gitignore 已忽略它）。

```markdown
# 课程配置：<课程名>

## 个人信息（封面）
| 字段 | 值 |
|---|---|
| 学校（封面大标题） | XX大学 |
| 封面样式 | simple / szu / …… |
| 课程名称 | 大学物理实验（2） |
| 课程编号 | |
| 学院 | |
| 姓名 | |
| 学号 | |
| 组号 | |
| 指导教师 | |

日期、实验地点每次向用户确认，不推测。

## 提交要求（老师原话或要点）
1. 文件命名：`{coursecode}-{group}-{author}-{expname}.pdf`（build.py 的 --name 写法）
2. 页序：封面 → 目的 → 原理 → 仪器 → 步骤 → 数据记录和处理 → 结果陈述及总结 → 思考题 → 教师评阅 → 评分栏 → 原始数据 → 预习试卷
3. 原始数据页、预习试卷首页（有签名）拍照放在最后，合成一个 PDF
4. 字号等格式要求：

## 评分栏
\labgrading{预习/20,操作及记录/40,数据处理与结果陈述/30,思考题/10}

## 实验安排（可选：轮换表、房间号）
| 周次 | 日期 | 实验 | 地点 |
|---|---|---|---|

## 文件夹约定
- 讲义/PPT：
- 参考报告：
- 成品输出：
- 工作区：

## 课程特有规则（与通用规则不同之处）
- 例：不确定度一律取一位；拟合必须用最小二乘法；……
```
