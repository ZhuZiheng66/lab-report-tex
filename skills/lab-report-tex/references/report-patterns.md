# 实验报告的规律（从 25 份真实报告总结）

样本：同一门课往届约 20 个实验的报告（PN 结、RLC 谐振、光敏电阻、光栅光谱仪、几何光学、双光栅、多普勒、密立根油滴、热膨胀、弗兰克-赫兹、杨氏模量、电位差计、磁滞回线、示波器、等厚干涉、比热容、逸出功、阿贝成像、霍尔效应）+ 本届学生 3 份已交报告 + 1 份预习报告。结论对其他学校、其他理工科实验课同样适用，因为差异主要在“模板和要求”，而那是每次从材料里读出来的。

## 1. 结构：模板决定，不是固定的

- **章节名和数量每门课、甚至每个实验都不同**。见过的写法：
  - 七段：目的 / 原理 / 仪器 / 内容与步骤 / 数据处理 / 结果陈述 / 思考题
  - 八段：……/ 五 数据记录 / 六 数据处理 / 七 结果陈述 / 八 实验总结与思考题
  - 合并：“实验结论与讨论”、“实验总结与思考题”
- **评分栏也随实验变**：同一门课里见过“数据处理与结果陈述 30 分”“数据处理 20 分 + 结果陈述实验总结 10 分”“数据处理 25 分 + 结果与讨论 5 分”。所以 `\labgrading` 的内容**照本次模板抄**，不要沿用上一份。
- 模板常带一句“报告内的项目或内容设置，可根据实际情况加以调整和补充”和格式注释（字号、原始数据单独起页附最后）。这些是硬性要求，写进需求清单。
- 预习试卷（题目.doc）是在线答题的成绩页，交报告时作为“预习试卷首页及成绩”附在最后，不是正文内容。

**做法**：开工时从模板、老师通知、讲义里抽出一份“需求清单”（章节及顺序、评分项、命名、页序、格式、讲义里点名要做的图/表/计算），用 `build.py --require` 在编译时逐项核对。

## 2. 实验的五种类型

每次先判断属于哪一类（可以混合），决定“数据处理”和“结果陈述”写什么。

| 类型 | 例子 | 数据处理核心 | 结果陈述要给出 |
|---|---|---|---|
| A 测定一个量 | 杨氏模量、逸出功、比热容、热膨胀系数、密立根油滴、电位差计、光速 | 逐差 / 最小二乘拟合 / 多次测量平均 → 代入公式 → 不确定度传递 | `(x ± u) 单位 (P=0.683)`、相对不确定度；与公认值/标称值比较的相对误差 |
| B 测特性曲线 | PN 结伏安、光敏电阻、RLC 谐振、磁滞回线、F-H 曲线、霍尔输出特性 | 画曲线（必要时对数轴、回线按顺序连）→ 读特征量（峰位、谐振频率、半功率带宽 Q、阈值电压、Bs/Br/Hc、斜率） | 曲线形状的定量描述（“在 x≈… 处达到最大值 …”），特征量数值，与理论趋势是否一致 |
| C 分布 / 扫描 | 螺线管轴向磁场、声场、温度分布 | 计算每点的导出量 → 分布曲线 | 最大/最小值及位置、对称性（两端数值对比）、均匀区范围 |
| D 仪器导出数据 | 光栅光谱仪（U 盘）、示波器存储、数据采集卡、软件仿真 | 读入 TXT/CSV（`fit_plot.py` 支持空白分隔、自动跳过说明行）→ 画谱 → 找峰 → 与已知谱线比对 | 峰位列表与标准值对照、误差；说明数据来源文件 |
| E 观察 / 定性 | 示波器使用、阿贝成像、几何光学成像、李萨如图形 | 截图/照片/手绘图整理成图，标注条件（档位、频率比、滤波器） | 逐项描述观察到的现象，并用原理解释；有可读数（周期、频率、放大率）的仍要算 |

E 类往届常写“本实验无数据”——这会丢“数据处理”分。只要屏幕上有刻度、档位，就能读出周期/频率/幅值并与信号源设定值比较。

## 3. 往届报告的常见失分点（我们要做得更好的地方）

| 往届的问题 | 本 skill 的做法 |
|---|---|
| 计算列留空（磁滞回线表里 H、B 两列空着） | 导出量全部由 analysis.py 算出，表格自动生成 |
| 公式是截图/MathType 图片，糊、不能改 | LaTeX 原生公式，编号可引用 |
| 结果只有一个数，没有不确定度，单位写错（“1.6511pa”） | `uncert.py` 修约，`siunitx` 排单位 |
| 结论空泛：“通过本次实验，我掌握了……的方法” | 结论条条带数值：r、相对误差、特征量、表号图号 |
| “对称分布”但两端数值 0.44 和 0.85 相差近一倍 | 写定性结论前先看数据是否支持；不对称就如实说并分析原因 |
| 同一常数前后两个值（灵敏度 174 / 177） | 常数只在 analysis.py 定义一次，用宏引用 |
| 结论与数据处理里的数不一致 | 两处都引用同一个宏 |
| 思考题答案照抄网上，与本次实验无关 | 先答原理，再落到本次数据（“本实验中 … 时 …”） |

## 4. 往届报告里值得保留的东西

- 仪器表写“名称 / 规格 / 量程 / 最小刻度 / 仪器误差”，后面的 B 类不确定度直接从这张表取 Δ仪。
- 数据处理里先给一个**代入具体数字的计算示例**，再给全表结果。
- 步骤写实际取的测量点（“Is 依次取 1.00、1.50 … 3.50 mA”），注意事项单列。
- 思考题保留题目原文，再“答：”。
- 篇幅：正文 3000–9000 字，图 2–10 张；数据越多的实验图表越多，文字不必更长。

## 5. 一份高分报告的检查表

- [ ] 章节、顺序、评分栏与本次模板一致（`--require` 通过）
- [ ] 每张表的计算列都填满；每张图有轴名“物理量/单位”、图题、在正文中被引用
- [ ] 至少一个代入数字的计算示例
- [ ] 最终结果有不确定度（A 类）或特征量数值（B/C/D 类），有效数字正确
- [ ] 与理论/公认/标称值比较，给相对误差；差得多时有具体原因分析
- [ ] 结论里每个形容词（线性、对称、一致、稳定）都有数字支撑
- [ ] 思考题结合本次数据
- [ ] 原始数据照片、预习试卷页按要求附在最后，方向正确、清晰
- [ ] 文件名符合命名规则
