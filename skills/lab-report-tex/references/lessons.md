# 踩过的坑

来自真实使用（Claude Code、豆包、Codex 上做过的多份大学物理实验报告），按出现频率排列。

## 数据与内容

1. **学长数据不能用**：学长的弗兰克-赫兹实验测的是氩，用户测的是汞。实验对象、仪器、参数都以本次讲义和用户记录为准。
2. **手写识别常见错**：负号丢失（对称测量里 V2/V4 应为负）、0.92 读成 6.92、正负号写反。用趋势核验，逐项列给用户确认。
3. **涂改值**：照片上划改的数（63→48），按老师签字认可的值，交付时说明。
4. **同一常数前后不一致**：霍尔元件灵敏度一处用 174、一处用 177。用前问用户以哪台仪器为准，全文统一（写成宏就不会不一致）。
5. **截断冒充修约**：脚本给 1.1857，正文写 1.185。修约应为 1.186。用 `uncert.py`/宏，别手抄。
6. **相对误差用了未修约的值**：W 报 5.25，误差却用 5.2513 算。统一用修约后的结果。
7. **形容词没有数据支撑**：写“磁场对称分布”，两端却是 0.44 mT 和 0.85 mT。写定性结论前先看数。
8. **沿用上一份的评分栏 / 章节**：同一门课不同实验的评分项分值不同（数据处理 30 / 25 / 20 分都见过），每次照本次模板。
9. **计算列留空、“本实验无数据”**：往届报告的常见失分点，见 report-patterns.md。

## 排版（为什么改用 LaTeX）

旧流程用 python-docx 改学校的 Word 模板，反复遇到：

- 嵌入的 Excel 图表（OLE）导出 PDF 时丢失，只剩图题；
- Word 自动编号标题被重复写成“二、二、”；
- 表格末尾强制分页多出空白页、表题和表格被拆到两页；
- 公式只能写成 `I=A·S·T²·exp(...)` 这样的行内文本；
- Word COM 导出遇到中文路径卡死、残留 WINWORD 进程。

LaTeX 方案把这些问题从结构上消掉：图是矢量 PDF、编号自动、表题与表格绑在一起、公式原生排版、命令行编译可复现。剩下要注意的是 [latex.md](latex.md) 里的几条。

## 工具环境

- Windows 默认 `python` 可能缺依赖：`check_env.py` 会列出来；也可以显式用装好依赖的解释器。
- `.doc`（老模板、学长报告）先另存为 docx/PDF 再读，原件不动。
- 中文 zip（学长资料包）文件名常是 GBK：`name.encode('cp437').decode('gbk')`。
- Git Bash 里 `python x.py | head` 可能报 `OSError: [Errno 22]`（管道提前关闭），无害；脚本已统一 UTF-8 输出。
- 手机照片带 EXIF 方向，LaTeX 不认，必须先过 `prep_photos.py`。
