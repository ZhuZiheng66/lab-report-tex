# 原始数据：转写、核对、冻结

手写原始数据是整份报告唯一的数据来源。这一步错了，后面算得再漂亮也是错的。

## 转写

1. 逐张照片、逐格转成 CSV：`data/raw.csv`。表头写“物理量/单位”（`Is/mA`、`Ua/V`），一个测量点一行或保持原表的宽表结构都可以。
2. **数值按原样字符串记录**：`0.40` 就写 `0.40`，不要变成 `0.4`；末位零是有效数字。
3. 多张照片拼同一张表时，按数值连续性确认拼接位置。
4. 看不清的格子写成 `?` 并记下位置，不猜。

## 可疑项清单（交给用户确认）

逐类检查，列成表给用户，一次问完：

| 类型 | 典型例子 | 怎么发现 |
|---|---|---|
| 负号丢失 / 写反 | 霍尔电压 V2、V4 应为负 | 对称测量的符号规律 |
| 数字形近 | 0.92 读成 6.92，1↔7，0↔6 | 与相邻点比较，看是否破坏单调/线性 |
| 涂改 | 63 划掉改 48 | 以老师签字认可的值为准，并在交付说明中写明 |
| 小数点位置 | 12.5 vs 1.25 | 量级与仪器量程是否相符 |
| 单位 / 量程切换 | 中途从 mA 换 μA | 表头、照片批注 |
| 漏记 | 某格空白 | 问用户，不补 |

再用物理规律交叉检查：该线性的看残差，该单调的看是否单调，该对称的看两端，峰距该相等的看间距。异常点**只标出、不删、不改**，在结果分析里说明。

## 冻结

用户确认后，`data/raw.csv` 视为只读。之后的换算都写进派生 CSV（`data/derived*.csv`）或 `analysis.py`，原始文件不再手改。若用户后来更正某个值，改 `raw.csv` 后**整条流水线重跑**（analysis.py → build.py），不要只改正文。

## 仪器导出数据、截图

- 光谱仪、示波器、采集卡、仿真软件导出的 TXT/CSV：原文件放 `data/` 里只读，`fit_plot.py` 能直接读（空白/制表符/分号分隔，自动跳过开头说明行）；需要换算时在 analysis.py 里生成派生文件。
- 正文里注明数据来自哪个文件、仪器设置（档位、积分时间、采样率）。
- 示波器屏幕截图、仿真截图当作图插入（`\labfig`），图题写清测量条件；屏幕上能读出的数（档位 × 格数）要读出来计算。

## 照片本身

- 原始数据照片、预习试卷签字页原样作为单独页面放在报告最后（`\labphotos`）。
- 用 `prep_photos.py` 只做转正、旋转、等比压缩；不裁剪、不调色、不修图。
- 用户的照片只嵌在旧 docx 里时，从 docx（zip）的 `word/media/` 取原图，比从 PDF 截图清晰。
