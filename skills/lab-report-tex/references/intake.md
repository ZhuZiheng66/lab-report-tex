# 材料识别：先弄清用户给的每个文件是什么

用户通常会把一堆东西一次性扔过来——模板、讲义、老师的通知截图、手写记录照片、学长报告、预习试卷——文件名还常常是 `IMG_2034.jpg`、`微信图片_2026…`、`新建文档(3).docx`。**在动手写任何内容之前，必须先把它们分清楚**：把学长报告当成模板、把预习试卷当成原始数据、把别人的数据当成用户的数据，都会让整份报告作废。

## 流程

1. **粗分**：`python <skill>/scripts/inventory.py <用户给的文件或文件夹>`。它按文件名和内容片段给出初判和置信度。
   - 压缩包：解压到**单独的新文件夹**再跑一次（中文 zip 文件名可能是 GBK：`name.encode('cp437').decode('gbk')`）。
   - `.doc/.ppt` 老格式：用 Word/WPS/LibreOffice 另存为 docx/pptx/pdf 再读，原件不动。
2. **逐个确认**：脚本只是线索。每个文件都要真正打开看——
   - **照片、截图、扫描 PDF 一律看图**，判断是哪一种（见下表），不能只看文件名。
   - 文档至少读开头一页和章节结构；PPT 至少读每页标题。
3. **出《材料清单》给用户确认**（一张表，见下方格式），同时列出**缺什么**和**有疑问的**。用户确认前不开始写报告。
4. 清单写进工作目录的 `requirements.md` 开头，后续步骤都以它为准。

## 各类材料怎么认

| 类型 | 典型样子 | 关键判据 | 在报告里的用途 |
|---|---|---|---|
| **报告模板** | 学校 Word 模板，封面有“课程名称/实验名称/报告人”下划线，后面是空的章节框、评阅栏、评分表 | 有框架、**几乎没填内容**（几百字、没有数据） | 决定封面、章节名与顺序、评分栏、格式注释 |
| **老师要求 / 通知** | 群通知截图、邮件、文档里的“提交要求”“命名格式”“截止时间”“评分标准” | 祈使句、命名规则、截止日期、扣分说明 | 写进需求清单：命名、页序、必做项 |
| **讲义 / 实验 PPT** | 课件，含实验目的、原理公式、仪器、步骤、数据表格式、思考题 | 讲解性质，没有学生的测量数据 | 目的、原理、仪器、步骤、思考题原文、要求做的图表 |
| **数据处理规则讲义** | 《不确定度评估与有效数字》之类 | 讲修约、A/B 类不确定度 | 覆盖通用规则 |
| **原始记录（手写）** | 手写表格照片，常有老师签字/盖章、涂改 | **手写数字 + 本次实验的物理量**；有签字通常就是原始记录 | **唯一数据来源**；照片原样附在报告最后 |
| **仪器导出数据** | 光谱仪/示波器/采集卡导出的 TXT/CSV，或软件截图 | 大量数字、仪器表头 | 数据来源，原文件只读 |
| **仪器/现象照片** | 拍的仪器铭牌、示波器屏幕、实验装置、干涉条纹 | 没有表格，是实物 | 仪器参数（铭牌）、观察类实验的图 |
| **预习试卷 / 预习报告** | 在线答题成绩页（单选题、标准答案、得分）或预习作业 | “预习”“题目”“标准答案” | 若老师要求，作为“预习试卷首页及成绩”附在最后；**不是数据** |
| **参考报告** | 学长/同学/自己上一份写好的报告 | 框架**填满了**：大段文字、数据表、结论 | 只借结构和写法；**其中的数据一律不用** |

### 容易认错的几对

- **模板 vs 参考报告**：外观一样。模板几乎是空的；参考报告填满了数字和结论。把参考报告当模板用，会把别人的数据、日期、姓名带进来。
- **原始记录 vs 参考报告里的数据表**：原始记录是**手写**的、是**这次**实验、通常有签字。参考报告里的表是打印的、是别人的。
- **原始记录 vs 预习试卷**：预习试卷是选择题和得分，没有测量数据。
- **本次实验 vs 别的实验**：照片里的物理量、仪器要和本次讲义对得上（测汞还是测氩？测的是 V_H 还是 I_P？）。对不上就问。
- **一张照片里两样东西**：常见“原始记录 + 预习试卷签字页”拍在一起，在清单里注明，需要时分别处理（不裁剪原图，只在清单里说明）。
- **多张照片拼一张表**：按表头和数值连续性确定顺序，在清单里写明拼接顺序。

## 《材料清单》格式

```markdown
| # | 文件 | 认定为 | 依据 | 用途 |
|---|---|---|---|---|
| 1 | 实验报告模版 空白(2).doc | 报告模板 | 封面+空章节+评分栏，未填内容 | 封面、章节顺序、评分栏 |
| 2 | 光拍法测光速.pptx | 讲义 | 有目的/原理/步骤/思考题 | 正文依据 |
| 3 | IMG_2034.jpg | 原始记录（第 1 页） | 手写数据表，有老师签字 | 数据来源，附在最后 |
| 4 | IMG_2035.jpg | 原始记录（第 2 页） | 接第 1 页的表 2 | 同上 |
| 5 | 微信图片_01.jpg | 预习试卷成绩页 | 单选题+得分 | 附在最后 |
| 6 | 光拍法学长.docx | 参考报告 | 已填满的往届报告 | 只参考结构，不用数据 |

**缺少**：老师的命名要求（模板里没写）——是否沿用上次的「课序号-组号-姓名-实验名称」？
**有疑问**：IMG_2036.jpg 是示波器屏幕照片，是否要放进报告的数据处理部分？
```

## 缺材料时

| 缺什么 | 怎么办 |
|---|---|
| 原始数据 | **停下来问**。没有原始数据不能开工，也不能用参考报告里的数据代替 |
| 讲义 | 问用户要；实在没有，原理和步骤可以按教材常识写，但要告诉用户“这部分没有讲义依据，请核对”，思考题必须要原文 |
| 模板 | 用 `cover=simple` 和常见章节顺序（report-patterns.md），告诉用户 |
| 老师要求 | 模板注释、讲义末页、上一份报告的命名里常有；都没有就问 |
| 个人信息、日期、地点 | 问，不推测 |
