# 数据处理、不确定度与有效数字

国内大学物理实验课的通行规则。**课程讲义里有不同规定时以讲义为准**，并把差异记进 lab-profile.md。

## 不确定度

| 情况 | 做法 |
|---|---|
| 单次测量 | 只算 B 类：u_B = Δ仪/√3（均匀分布） |
| 多次测量 | u_A = s/√n（s 用贝塞尔公式），u = √(u_A² + u_B²) → `uncert.py mean` |
| 和差函数 N=x±y | u_N = √(u_x² + u_y²) |
| 积商函数 N=x^a·y^b/z^c | u_N/N = √[(a·u_x/x)² + (b·u_y/y)² + (c·u_z/z)²] |
| 逐差法 | `uncert.py diff`：结果 = Σ差/(差的个数×间隔)；报告里写清 u_A、u_B 的来源 |
| 拟合斜率 | `fit_plot.py` 给的 u(k) 是统计不确定度；要合成仪器误差时写明 |

Δ仪：先查讲义 / 仪器铭牌 / 教材；数字表常为“a%×读数 + n 个字”。查不到就问用户，或明确写“按……估计”，不要编。
分清：仪器误差限 Δ仪、标准不确定度 u、合成不确定度、相对不确定度 E=u/N。

## 有效数字与修约

- 不确定度取 1~2 位（首位 1、2 时取两位），**只进不舍**；相对不确定度最多两位。
- 测量值末位与不确定度末位对齐，“四舍六入五凑偶”（`uncert.py` 已实现）。
- 直接读数 = 准确位 + 一位估读位；原始数据照原样，不补零也不删零。
- 运算：加减按小数位最少的对齐；乘除按有效位最少的对齐；常数取位不少于其他量。
- 结果写法：`W = (5.25 ± 0.11) eV (P=0.683)`，相对不确定度 2.0%。
- **相对误差用修约后的结果算**，前后一致（用 5.2513 算得 15.7%、用 5.25 算得 15.6%，正文只能出现一个）。

## 图

- 用 `fit_plot.py` 出 **PDF 矢量图**，`\labfig` 插入；坐标轴写“物理量/单位”（`$V_H$/mV`）。
- 数据点用标记、拟合线用实线；图题在图下方、表题在表上方（文档类已设好）。
- 曲线类（如 F-H 的 I_P-U_G2）用实际数据点连线；峰位以记录值为准，脚本找峰只作辅助。
- 外延法用 `--extend-to-zero` 把拟合线画到 x=0。

## 结论和分析

- “线性”给 r；“对称”给两端数值；“符合理论”给公认值和相对误差。
- 异常点：指出是哪个点、偏多少、可能原因（标明“可能”），不删点、不改点。
- 误差分析具体到“哪个操作 → 影响哪个量 → 往哪个方向偏 → 怎么改进”，不写空泛的“人为因素”。
