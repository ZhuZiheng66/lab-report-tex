# 各章节怎么写

文字风格：学生口吻、短句、平实；篇幅与往届报告相近。“由表 1 及图 1 可知……拟合斜率 k=…，r=…”这种句式。不写“本实验圆满成功”“加深了对……的理解”一类套话。

| 章节 | 写法 |
|---|---|
| 实验目的 | 讲义原句逐条，`1．2．3．` |
| 实验原理 | 按讲义分 `\labsub` 小节；关键公式用 `equation` 编号；每个符号说明含义和单位；原理图可用 `\labfig`（讲义截图或自己画） |
| 实验仪器 | 仪器清单 + 参数表（名称/型号/量程/分度值/Δ仪）。参数从讲义、铭牌、用户照片来，查不到就问 |
| 实验内容与步骤 | 按**实际做的**测量点写（取了哪些值、间隔多少），加注意事项；不写没做的步骤 |
| 数据记录和处理 | 数据表（计算列填满）→ 代入数字的计算示例 → 图 → 拟合/逐差结果 → 不确定度推导 → 最终结果；按实验类型调整，见下表 |
| 结果陈述及总结 | 每条引用表号/图号和具体数值；与理论值/标称值比较给相对误差；误差来源具体到操作；一两句总结 |
| 思考题 | 题目原文 + 答；尽量结合本次数据回答 |

## 按实验类型写“数据处理”和“结果陈述”

| 类型 | 数据处理 | 结果陈述 |
|---|---|---|
| 测定一个量 | 逐差/拟合/平均 → 代入公式 → 不确定度传递 | `(x±u) 单位 (P=0.683)`，相对不确定度，与公认值的相对误差 |
| 特性曲线 | 曲线图（对数轴、回线按顺序连线）+ 特征量读取（峰、谐振频率、Q、阈值、Bs/Br/Hc） | 曲线形状的定量描述、特征量数值、与理论趋势对照 |
| 分布 | 每点导出量 → 分布曲线 | 极值及位置、两端数值、均匀区 |
| 仪器导出 | 读入导出文件 → 谱图 → 峰位表 → 与标准值比对 | 峰位与标准值、误差，注明数据文件 |
| 观察定性 | 截图/照片整理成带条件标注的图；能读的数（周期、频率、放大率）照样算 | 逐项描述现象并用原理解释；不要写“本实验无数据” |

详见 [report-patterns.md](report-patterns.md)。

## 章节顺序与命名

**以本次模板为准**（章节名、是否合并“实验总结与思考题”、评分栏各项分值都可能每个实验不同），写进 requirements.md 后用 `build.py --require` 核对。常见顺序：封面 → 实验目的 → 实验原理 → 实验仪器 → 实验内容与步骤 → 数据记录和处理 → 结果陈述及总结 → 思考题 → 教师评阅意见 → 成绩评定 → 原始数据（单独页）→ 预习试卷（单独页，若有）。

## 参考报告怎么用

- 学长/同学报告：看结构、原理的讲法、思考题的方向。**不抄数据**；实验条件（气体种类、仪器型号、测量范围）常常不同。
- 上一份自己的报告：沿用措辞风格和篇幅。
- 讲义与参考报告冲突时，以讲义和用户实际操作为准。
