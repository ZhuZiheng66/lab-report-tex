# 实验目的
1．了解产生霍尔效应的物理原理；
2．学习控制变量法和对称测量法；
3．测量霍尔器件的输出特性；
4．利用霍尔元件测量长直螺线管的轴向磁场分布。

# 实验原理
## （一）霍尔效应
把载流半导体薄片置于与电流方向垂直的磁场中，载流子受洛伦兹力作用发生横向偏转，在薄片两侧积累电荷并建立横向电场。洛伦兹力与横向电场力平衡时，两侧形成稳定的霍尔电压
!式 V_{H} = K_{H} I_{s} B　　　　（1）
式中 I_{s} 为工作电流（mA），B 为磁感应强度（T），K_{H} 为霍尔器件灵敏度（mV/(mA·T)），由材料与几何尺寸决定。
## （二）附加电动势与对称测量法
实测电压中还叠加有不等电位差、爱廷豪森效应、能斯特效应和里纪-勒杜克效应等附加电动势。分别测量 (+B,+I_{s})、(−B,+I_{s})、(−B,−I_{s})、(+B,−I_{s}) 四种组合下的电压 V_{1}～V_{4}，取
!式 V_{H} = (V_{1} − V_{2} + V_{3} − V_{4}) / 4　　　　（2）
可消除大部分附加电动势。
## （三）用霍尔元件测磁场
由式（1），已知 K_{H}，测出 V_{H} 与 I_{s} 即可求得
!式 B = V_{H} / (K_{H} I_{s})　　　　（3）

# 实验内容与步骤
1．**测绘 V_{H}-I_{s} 曲线**：先将霍尔电压调零，取 I_{m}=0.300 A，工作电流 I_{s} 依次取 1.00、1.50 … 3.50 mA，每个 I_{s} 测四种方向组合下的 V_{1}～V_{4}。 <!-- lrt:literal 工作电流的测量设定点 -->
2．**测绘 V_{H}-I_{m} 曲线**：保持 I_{s}=3.00 mA，I_{m} 依次取 0.100～0.500 A（间隔 0.100 A），同法测量。
3．**测螺线管轴向磁场**：I_{s}=3.00 mA、I_{m}=0.300 A，霍尔片沿轴线从 X=0 移到 200 mm，每隔 10 mm 测一组 V_{1}～V_{4}。
**注意事项：**换向时先把电流调到零；霍尔片移动时不要碰到螺线管内壁；工作电流不超过 10 mA。

## 3．中心点磁场的不确定度
V_{1}～V_{4} 为单次测量，只计 B 类。对 V_{H}≈{{VHC}} mV，各电压分量 Δ_{仪}≈{{DV}} mV，u_{B}=Δ_{仪}/√3。由式（2），
!式 u(V_{H}) = √(4u_{B}^{2}) / 4 = u_{B} / 2 ≈ {{UVH}} mV，u(V_{H})/V_{H} = {{RelVH}}%
K_{H} 标称误差 ±2%，u(K_{H})/K_{H}=2%/√3={{RelKH}}%；I_{s}=3.00 mA 时 u(I_{s})/I_{s}={{RelIs}}%。式（3）为积商形式：
!式 u(B)/B = √[(u(V_{H})/V_{H})^{2} + (u(K_{H})/K_{H})^{2} + (u(I_{s})/I_{s})^{2}] = {{RelB}}%
中心点磁场：B=({{BVal}}±{{BU}}) mT（P=0.683）。

# 结果陈述及总结
1．由表2及图1，V_{H} 随 I_{s} 线性增大，斜率 {{FitIsK}} mV/mA，r={{FitIsR}}，截距接近零，即 V_{H}∝I_{s}，与式（1）一致。
2．由表3及图2，V_{H} 随 I_{m} 线性增大，斜率 {{FitImK}} mV/A，r={{FitImR}}。螺线管内 B∝I_{m}，故 V_{H}∝B，霍尔效应测磁场的原理得到验证。
3．由表4及图3，轴线上磁场中间强、两端弱：X≈100～110 mm 处最大，B=({{BVal}}±{{BU}}) mT；X={{XLeft}} mm 端 B={{BLeft}} mT，X={{XRight}} mm 端 B={{BRight}} mT，两端相差约 {{EndRatio}} 倍，分布并不严格对称。可能原因是位移标尺零点与螺线管端口没有对齐，测量区间相对螺线管中心偏向一侧。
4．误差主要来自 K_{H} 的标称误差（贡献 {{RelKH}}%，在 {{RelB}}% 的合成不确定度中占主导），其次是工作电流读数；对称测量法已消除大部分附加电动势。

# 思考题
**1．霍尔电压的大小与哪些因素有关？**
答：由 V_{H}=K_{H}I_{s}B，霍尔电压与工作电流 I_{s}、磁感应强度 B 成正比；灵敏度 K_{H} 由材料（载流子类型与浓度）和厚度决定，并随温度变化。本实验中增大 I_{s} 或 I_{m} 时 V_{H} 均线性增大（r={{FitIsR}}、{{FitImR}}），与理论一致。
**2．若已知霍尔器件的性能参数，用霍尔效应法测量一个未知磁场时，测量误差有哪些来源？**
答：① V_{H} 的测量误差（毫伏表仪器误差与读数误差）；② 对称测量法未完全消除的附加电动势；③ 工作电流 I_{s} 的误差及波动；④ K_{H} 的标称误差与温漂——本实验中它是最大的一项（{{RelKH}}%）；⑤ 霍尔片平面与磁场不垂直，实际测到 Bcosθ；⑥ 霍尔片的定位误差，在磁场变化快的螺线管端部影响尤其大；⑦ 磁场本身的不均匀性。
